# 坦克大战 · Tank Battle

一个纯 HTML5 Canvas 实现的经典坦克大战游戏，单文件即可运行，无需任何依赖。

## 🎮 玩法

- **目标**：消灭所有敌方坦克，同时**保护你的基地 🦅**。基地被摧毁则游戏结束。
- 共 **3 关**，通关后获胜。

## ⌨️ 操作

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` / `方向键` | 移动 |
| `空格` / `J` | 开火 |
| `P` / `Esc` | 暂停 |
| `Enter` | 开始 / 重新开始 |

## 🧱 地图元素

| 元素 | 说明 |
| --- | --- |
| 🟫 砖墙 | 可被炮弹击碎 |
| ⬜ 钢墙 | 不可被击碎 |
| 🟦 水域 | 坦克无法通过，炮弹可越过 |
| 🌲 树林 | 可藏身，坦克与炮弹都能穿过 |
| 🦅 基地 | 必须保护的目标 |

## 🚀 运行方式

1. 直接用浏览器打开 `index.html` 即可游玩；
2. 或通过 [GitHub Pages](https://pages.github.com/) 托管在线游玩。

## ✨ 特性

- 3 种敌人：普通坦克、快速坦克、重型坦克（2 点生命）
- 得分、最高分（本地存储）、生命、关卡系统
- 粒子爆炸、屏幕震动、Web Audio 音效
- 响应式布局，适配桌面与移动端
